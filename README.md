## 使用说明

- HTML 是静态导出快照，不会随原始页面自动更新；需要更新时重新导出并覆盖同名文件。
- 页面内个别平台注入脚本只在原平台环境生效，不影响本地阅读正文。
- 在另一台设备上获取：`git clone https://gitee.com/azhangpenga/swaps.git`，之后用 `git pull` 同步最新内容。
